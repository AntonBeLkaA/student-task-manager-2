# Клікабельний прототип

## Програмний продукт

TaskFlow Student.

## Призначення

Прототип демонструє навігацію між списком завдань, формою створення та переглядом завдання.

Екрани створено на основі ескізів практичної №13. У Figma вони розміщені на сторінці Main Prototype.

## Екрани

1. 01 — Task List: список завдань.
2. 02 — Create Task: форма створення.
3. 03 — Task Details: перегляд завдання.

## Основний сценарій

1. Студент відкриває список.
2. Натискає «Нове завдання».
3. Переглядає форму з демонстраційними даними.
4. Натискає «Зберегти».
5. Повертається до списку.
6. Відкриває картку завдання.
7. Повертається до списку кнопкою «До списку завдань».

## Реалізовані переходи

- «Нове завдання»: список → форма.
- «Зберегти»: форма → список.
- «Скасувати»: форма → список.
- Картка завдання: список → перегляд.
- «До списку завдань»: перегляд → список.

## Обмеження

Поля та картки містять підготовлені демонстраційні дані. Реальне введення, перевірка й збереження даних не реалізовані.

## Результат перевірки

### Самоперевірка

- Створення та повернення до списку: зазначити фактичний результат.
- Перегляд картки й повернення: зазначити фактичний результат.
- Скасування: зазначити фактичний результат.

### Перевірка іншою людиною

- Статус: ще не проведена.
- Спостереження: заповнити після перевірки.
- Виправлення: зазначити за наявності.
- Повторна перевірка: зазначити результат після виправлення.
