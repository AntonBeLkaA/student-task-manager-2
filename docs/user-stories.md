# User stories програмного продукту

## Загальна інформація

**Назва продукту:** TaskFlow Student
**Основний актор:** Студент
**Додаткові актори:** відсутні
**Мета:** Описати потреби студента для основних функцій MVP та визначити умови їх приймання.

## US-01. Створення навчального завдання.

**User story:** як студент, я хочу створити навчальне завдання із зазначенням дати, щоб не забути про строк його виконання.

**Критерії приймання:**
- Після збередження нове задвання відображається у списку з вибраною категорією, якщо її було зазначено.
- Завдання без назви не зберігається.

**Пріоритет:** Високий.
**Пов'язана функція MVP:** створення завдання
**Пов'язана вимога:** FR-01.

## US-02. Перегляд навчального завдання.

**User story:** як студент, я хочу переглядати список завдань, щоб бачити актуальний обсяг навчальної роботи.

**Критерії приймання:**
- У списку відображаються створенні завдання.
- Біля кожного завдання показано його дату та статус.

**Пріоритет:** Високий.
**Пов'язана функція MVP:** перегляд завдання
**Пов'язана вимога:** FR-02.

## US-03. Редагування навчального завдання.

**User story:** як студент, я хочу редагувати створене завдання, щоб випривляти помилкову або застарілу інформацію.

**Критерії приймання:**
- Студент може змінити назву, опис або дату завдання, а також вибрати або прибрати його категорію.
- Після збереження у списку відображаються оновлені дані.

**Пріоритет:** середній.
**Пов'язана функція MVP:** редагування завдання
**Пов'язана вимога:** FR-03.

## US-04. Видалення навчального завдання.

**User story:** як студент, я хочу видаляти непотрібні  завдання, щоб список залишався актуальним.

**Критерії приймання:**
- Перед видаленням система запитує пітвердження.
- Після пітвердження завдання зникає зі списку.

**Пріоритет:** середній.
**Пов'язана функція MVP:** Видалення завдання
**Пов'язана вимога:** FR-04.

## US-05. Зміна статусу навчального завдання.

**User story:** як студент, я хочу позначити завдання виконаним, щоб відрізняти завершену роботу від поточної.

**Критерії приймання:**
- Студент може змінити статус завдання на "Виконано".
- Виконане завдання візуально відрізняється від невиконаного.

**Пріоритет:** Високий.
**Пов'язана функція MVP:** зміна статусу завдання
**Пов'язана вимога:** FR-05.
