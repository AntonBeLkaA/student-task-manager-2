# Опис програмного продукту

## Назва

Student Task Manager

## Проблема

Студентам потрібно контролювати навчальні завдання,
строки їх виконання та поточний стан.

## Цільова аудиторія

Студенти закладів освіти.

## Мета продукту

Допомогти студенту організувати навчальні завдання
та контролювати їх виконання.

## Основні функції

- створення завдань;
- перегляд завдань;
- пошук завдань;
- фільтрація завдань;
- сортування за пріоритетом;
- робота з категоріями;
- зміна стану завдання.

## MVP

123 Базова версія продукту дозволяє створювати,
переглядати та знаходити навчальні завдання,
працювати з категоріями та контролювати їх стан.
