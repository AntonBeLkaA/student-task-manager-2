# Перевірка вимог програмного продукту

## Загальна інформація

**Назва продукту:** Менеджер навчальних завдань.

**Остаточний список вимог:** [requirements.md](requirements.md).

**Перевірено:** 5 функціональних і 3 нефункціональні виомги.

**Мета перевірки:** уточнити формулювання, перевірити можливість тестування, відстутність дублювання  й суперечностей та відповідності MVP.

## Результат перевірки

| Код | Результат | Рішення |
| :--- | :--- |  :--- |
| FR-01 | Зрозумілі дія, потрібні данні та очікуваний результат | Без змін |
| FR-02 | Описує окрему функцію перегляду завдань | Без змін |
| FR-03 | Указано, які саме дані можна редагувати | Без змін |
| FR-04 | Не був прямо описаний результат скасування видалення | Уточненно |
| FR-05 | Обидва можливі статуси та перехід між ними зрозумілі | Без змін |
| NFR-01 | Не було названо конкретні сторінки для перевірки | Уточнено |
| NFR-02 | Не були уточнені умови поторного запуску браузера | Уточнено |
| NFR-03 | Не було названо конкретні дії з клавіатури | Уточнено |


Дубльованих і суперечливих вимог не вивявленно. FR-01, FR-02, FR-03 і FR-05 не змінювались після перевірки.

## Виявленні проблеми та виправлення


### FR-04 Видалення завдання

**Проблема:** не описано результат скасування.

**Було:** система повинна дозволяти користувачеві видалити завдання після підтвердження цієї дії.

**Стало:** після вибору дії видалення система повинна запитати підтвердження. Після підтвердження вона повинна прибрати вибране завдання зі списку, а після скасування залишити його без змін.

**Причина зміни:** визначено результат для підтвердження і скасування.

### NFR-01. Адаптивність інтерфейсу

**Проблема:** словосполучення «основні сторінки» не визначало, що саме перевіряти.

**Було:** основні сторінки продукту повинні відображатися на екранах шириною 320, 768 і 1440 пікселів без горизонтальної прокрутки основного вмісту.

**Стало:** сторінка списку завдань і форма створення завдання повинні відображатися на екранах шириною 320, 768 і 1440 пікселів без горизонтальної прокрутки основного вмісту.

**Причина зміни:** названо конкретні частини продукту.

### NFR-02. Збереження даних

**Проблема:** не визначено профіль браузера для перевірки.

**Було:** збережені завдання та їхні статуси повинні залишатися доступними після перезавантаження сторінки й повторного запуску браузера.

**Стало:** після створення завдання або зміни його статусу ці дані повинні залишатися доступними в тому самому профілі браузера після перезавантаження сторінки та повторного запуску браузера.

**Причина зміни:** уточнено умови, за яких перевіряється збереження даних.

### NFR-03. Керування з клавіатури

**Проблема:** слова «основні дії» не визначали перелік дій.

**Було:** користувач повинен мати змогу відкрити форму, заповнити її та виконати основні дії із завданнями за допомогою клавіатури без використання миші.

**Стало:** користувач повинен мати змогу за допомогою клавіші Tab перейти до полів і кнопок форми створення завдання, а також створити завдання та змінити його статус за допомогою клавіатури без використання миші.

**Причина зміни:** названо конкретні дії, які потрібно виконати без миші.


## Перевірюваність вимог

| Код | Що потрібно перевірити | 
| :--- | :--- | 
| FR-01 | Після збередження завдання з указаними даними воно з'являється у списку.| 
| FR-02 | Список показує створенні завдання, їхні дати та статуси.|
| FR-03 | Після редагування відображаються оновленні дані.| 
| FR-04 | Після скасування завдання залишається, після видалення зникає. | 
| FR-05 | Статус змінюється на "Виконано" і назад на "Не виконано"ю|
| NFR-01 | На ширинах 320, 768 і 1440 пікселів визначені сторінки не мають горизонтальної прокрутки основного вмісту. | 
| NFR-02 | Завдання та статус залишаються в тому самому профілі після перезавантаження сторінки й браузераю | 
| NFR-03 | Зазначені дії можна виконати з клавіатури без миші. |

| Функція MVP | Вимога | Відповідність |
|:---|:---:|:---:|
| Створення завдання | FR-01 | Так |
| Перегляд завдань | FR-02 | Так |

| Видалення завдання | FR-04 | Так |

Кожна перелічіна функція MVP має відповідну функціональну вимогу.


## Висновок

Перевірено п'ять функціональних і три нефункціональних вимоги. Уточнено FR-04, NFR-01, NFR-02 і NFR-03. Решту чотри вимоги залишено без змін після перевірки. дублювання і суперечностей не виявленно. Для кожної вимоги визнечено спосіб перевірки, а функції MVP пов'язані з остаточним списком вимог.
