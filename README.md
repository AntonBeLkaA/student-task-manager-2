# TaskFlow Student

## Короткий опис

TaskFlow Student — навчальний вебзастосунок для студентів, який допомагає зберігати завдання з різних дисциплін і бачити найближчі дедлайни.

## Мета продукту

Допомогти студенту не пропускати строки виконання навчальних завдань.

## Навчальна дисципліна

Технологія створення програмних продуктів.

## Картка програмного продукту

### Назва продукту
TaskFlow Student

### Короткий опис
TaskFlow Student - ввебзастосунок для студентів, який дозволяє зберігати навчальні завдання з різних дисциплін і котролювати їх виконання.

### Проблема
Студенти отримують завдання через декілька чатів і навчальних систем. Через це вони витрачають час на пошук інформації та можуть пропускати строки виконання.

### Цільова аудиторія
Студенти коледжу, які вивчають декілька дисциплін і використвують преважно смартфони.

### Основна користь
Студент швидко бачить найближчі завдання й витрачає меньше часу на пошук інформції

### Мета продукту
Допомогти студенту зберігати актуальні навчальні завданння в одному місці та своєчасно виконвувати їх.

### Цінісна пропозиція
Taskflow Student допомагає студенту коледжу контролювати навчальні деделайни, об'єднуючи завдання з різних дисциплін в одному зрозумілому списку.

### Основний користувацький сценарій

1. Користувач відкриває застосунок Taskflow Student
2. Натискає кнопку додавання завдання
3. Уваодить назву завдання
4. Вибирає дисципліну
5. Встановлює дату виконання. (дедлайн)
6. Зберігає завдання
7. Переглядає новостворенне завдання у загальному списку
8. ПППісля виконання змінює статутс завдання

### Функції MVP

1. **Створення завдання.** Корситувач указує назву, дисципліну та дату виконання.
2. **Перегляд списку.**  Користувач бачить усі ствоернні завдання.
3. **Зміна статусу.** Завдання можна позначити виконанним.
4. **Видалення завдання.** Помилково створенне або непотрібне завдання можна видалити.
5. **Відображення найближчого строку.** Користувач бачить найближчий строк виконання.

### Функції майбутніх версій

- нагадування;
- пошук;
- фільтрація;
- календар;
- статистика;
- групові задвання;

### Межі першої вресії
- викладачі не створюють завдання;
- синхронізація з навчальними плафтормами відсутня;
- вбудований чат;
- складна аналітика не входить до MVP;
