# TaskFlow Student

## Короткий опис

TaskFlow Student — навчальний вебзастосунок для студентів, який допомагає зберігати завдання з різних дисциплін і бачити найближчі дедлайни.

## Мета продукту

Допомогти студенту не пропускати строки виконання навчальних завдань.

## Автор

Іван Петренко, група 31КН(с).

## Статус проєкту

Навчальний проєкт. Етап: підготовка репозиторію.

## Навчальна дисципліна

Технологія створення програмних продуктів.
