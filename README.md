# TaskFlow Student

TaskFlow Student — навчальний проєкт менеджера навчальних завдань для студентів. Ідея продукту полягає в тому, щоб зберігати завдання, строки їх виконання та статуси в одному місці.

## Статус проєкту

Проєкт перебуває на етапі проєктування.

Підготовлено вимоги, user stories, діаграми, ескізи екранів і клікабельний прототип у Figma.

Програмна реалізація застосунку в межах цього курсу не створювалася.

## Спроєктовані можливості MVP

- створення навчального завдання;
- перегляд списку завдань;
- редагування завдання;
- видалення завдання;
- зміна статусу виконання.

Клікабельний прототип демонструє вибраний сценарій навігації між основними екранами.

## Використані інструменти

- Markdown — оформлення документації;
- Mermaid — створення діаграм;
- Figma — ескізи та клікабельний прототип;
- Git і GitHub — збереження матеріалів та історії змін.

## Як переглянути матеріали

1. Відкрийте цей репозиторій на GitHub.
2. Перейдіть за посиланнями в розділі «Документація».
3. Для перегляду інтерактивної моделі відкрийте прототип у Figma.

Установлення програмних залежностей не потрібне.

## Як переглянути прототип

1. Відкрийте посилання на прототип.
2. Почніть зі списку завдань.
3. Натисніть «Нове завдання», щоб відкрити форму.
4. Натисніть «Зберегти» або «Скасувати», щоб повернутися до списку.
5. Натисніть картку завдання, щоб відкрити детальну інформацію.
6. Натисніть «До списку завдань», щоб повернутися.

## Обмеження прототипу

- поля містять заздалегідь підготовлені демонстраційні значення;
- реальне введення та збереження даних не реалізовані;
- кнопки демонструють переходи між екранами;
- прототип охоплює вибраний сценарій, а не всі можливості майбутнього продукту.

## Подальший розвиток

Наступним етапом може бути програмна реалізація інтерфейсу, логіки роботи та збереження даних.
